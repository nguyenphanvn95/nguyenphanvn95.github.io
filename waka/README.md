# Waka Downloader — GitHub Pages CDN

Các file JS được host tại đây để userscript `waka-downloader.user.js` load qua `@require`.

## Files

| File | Mô tả |
|------|-------|
| `epub-decode.js` | Giải mã XHTML đã mã hoá (AES/CryptoJS) |
| `epub-builder.js` | Đóng gói EPUB từ files và OPF |
| `metadata-injector.js` | Nhúng metadata vào EPUB blob |
| `audio-content.js` | UI tải sách nói MP3 |

## Cài userscript

1. Cài [Tampermonkey](https://www.tampermonkey.net/) hoặc [Violentmonkey](https://violentmonkey.github.io/)
2. Mở file `waka-downloader.user.js` → cài đặt
